# 0.4.6 local development build

- Removed elevated permission: the existing host Runner uses its ordinary-user
  token path even when WinShun itself is elevated. No new privilege broker added.
- Retired the administrator-only scan preference; old saved values are ignored.
- Explicit WinGet machine scope can be reviewed without an elevated plugin:
  WinGet / installer owns UAC. No automatic privilege-switching retry is attempted.
  This does not guarantee that every installer supports automatic elevation.
- Scoop global remains blocked without an elevated execution path.
- 0x8A15007D now has a diagnostic task summary; unsuccessful state verification
  is no longer logged as green success.
- Scope buttons indicate selection; successful tasks end with Completed, and
  two-stage chains no longer have an extra trailing arrow. Verification updates
  the task's current phase before the read-only query.
- No real package install, upgrade or uninstall was performed for this validation.
