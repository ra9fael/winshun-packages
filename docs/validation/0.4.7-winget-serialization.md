# 0.4.7 local validation — WinGet mutation serialization

WinGet uses a shared per-user SQLite state database. The plugin's refresh used
parallel WinGet processes, and the task queue could start an uninstall while a
refresh was still running. That combination produced `0x87AF0008` (`attempt to
write a readonly database`) even in a normal-user process.

All child processes whose executable is `winget.exe` are now serialized in the
platform runner. Scoop and unrelated installers are unaffected. The error is
also reported as a database-write failure rather than an uninstaller failure;
the task remains failed and verification remains non-successful.

The local direct ordinary-user command `winget list --id sigoden.Dufs --exact`
returned Dufs 0.47.0. No package was removed during validation.
