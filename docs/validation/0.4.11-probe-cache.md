# 0.4.11 local validation — persisted backend probe verdict

## What was measured first

On this machine, before any `winget list` runs, each new plugin process paid:

```text
cmd /c exit 0        21 ms   (childProcessesAllowed)
winget --version    135 ms
winget --help       119 ms
```

≈ 275 ms and three child processes, every launch, to learn something that only
changes when the binary changes.

## What changed

- New pure module `src/core/probe_cache.cpp` with `Record` (state, detail,
  version, program, stamp, observedAt) and the rule:
  a verdict is reused only when the stamp matches **and** the verdict is
  `Ready`/`Unsupported`. `Missing`/`Denied`/`Unknown` are never reused — they are
  the transient cases a new process should retry.
- Stamp is `size:last-write-time` of the exact file probed
  (`platform::fileStamp`): WinGet's resolved `winget.exe`, Scoop's
  `shims\scoop.ps1` (not powershell.exe, which survives a Scoop uninstall).
- `Adapter::seedProbe()` / `probeStampPath()` let the controller install a
  persisted verdict before the first `probeCached()`.
- Written to `<data>\probe.json` after every scan; a scan where both backends
  failed never overwrites a good file.
- An explicit 刷新 and 清除缓存 call `invalidateProbe()`, so "look again" really
  looks again.
- The settings popup reports `探针：复用上次结果（WinGet v1.29.380、Scoop unknown）`
  or `探针：本次启动会重新检测`, so the behaviour is visible rather than implied.

## Verification

```text
run 1  --refresh            -> probe.json written:
       winget stamp 0:134346684574416268
       scoop  stamp 236:134389598828268238
run 2  --settings-popup     -> 探针：复用上次结果（WinGet v1.29.380、Scoop unknown）
```

Tests:

- core: 319 checks, 0 failures (16 new: stamp match/mismatch, refusal never
  reused, unsupported reused, round trip with escaped detail, unknown version and
  stamp-less record refused).
- fixture: 3670 checks, 0 failures (new: a seeded `Ready` verdict is returned by
  `probeCached()` without running the backend, proven by seeding a verdict while
  the adapter points at a non-existent executable; a seeded `Denied` is not
  reused).
- scoop / process / protocol / manifest unchanged and passing.

No package was installed, upgraded or removed for this validation.
