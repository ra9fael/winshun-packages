# 0.4.12 local validation — pin cache, version-pinned details, per-backend freshness

Three gaps from the previous review, each verified against the real backends in
the development harness.

## 1. Pin list persisted (`pins.json`)

`winget pin list` costs one process. It was re-read on every refresh and every
new plugin process, although only an explicit pin/unpin changes it.

- New pure module `src/core/pins_cache.cpp` (`pinsVersion: 1`, `observedAt`,
  `id -> policy`).
- `WingetAdapter::seedPins/invalidatePins/pinsKnown/cachedPins`;
  `invalidateCaches()` no longer drops pins (that was the "every scan" behaviour).
- Seeded at startup when the stored timestamp is within `refreshMinutes`;
  written after a scan that actually read it; dropped when a task finishes and by
  "clear cache".

Measured with WinGet's own diagnostic logs (`pin' 'list` command lines):

```text
cold scan (no pins.json): 273 -> 274   (one pin list)
warm scan (pins.json):    274 -> 274   (none)
```

## 2. Detail cache pinned to the installed version

An entry now stores the version the package had when it was fetched. It stays
valid while that version is still installed, instead of expiring after 30
minutes; rows that are not installed keep the time-based TTL.

Measured (`show' '--id` command lines, entry aged three hours, same selection):

```text
before: 151   after: 151   -> no winget show, cache hit
```

## 3. Per-backend freshness

Each backend carries its own timestamp (`wingetAt` / `scoopAt` in `cache.json`;
older files fall back to `observedAt`). A refresh queries only the backends that
are actually stale or whose last attempt was not Ready.

Measured: after a full scan, Scoop's stamp was aged three hours and the window
opened normally:

```text
wingetAt 2026-11-15T00:56:29Z -> unchanged
scoopAt  2026-11-14T21:58:02Z -> 2026-11-15T00:58:09Z
```

Only Scoop was queried; the WinGet list and its `--upgrade-available` query (the
most expensive one here) were skipped. A task finishing still forces both, since
what changed on disk is not known per backend.
